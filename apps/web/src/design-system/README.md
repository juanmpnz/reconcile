# Reconcile internal design system

`index.ts` is the public catalog. Stable subpath imports (`design-system/controls`, `design-system/data-table`, etc.) are supported to keep dependencies explicit. `components/ui/*` only re-exports the same implementations for compatibility; it does not own duplicate controls.

Feature modules compose these components and must not render native controls or tables directly. ESLint enforces that boundary. Semantic content (paragraphs, headings, sections and links) remains valid JSX; repeated layout patterns use the shared building blocks.

| Area                | Public components                                                                        | Contract                                                                                                                                                                                                                       |
| ------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Controls            | Input, Textarea, Checkbox, FileInput, Select                                             | Native form props, refs, IDs, labels, disabled/required/readOnly, validation and keyboard semantics; Select uses the shared Radix implementation, including its accessible form bridge.                                        |
| Fields              | Field, FormField, Label                                                                  | Field connects label, hint and error IDs. Existing default required behavior is preserved; `required={false}` is supported. FormField composes complex labeled controls.                                                       |
| Actions             | Button                                                                                   | default, outline, ghost; pending implies disabled and aria-busy. `unstyled` is for table headers/resizers and inline actions while retaining behavior. Submit type is preserved, including existing native default semantics.  |
| Collections         | DataTable, TableColumn, renderString/Number/Currency/Date/Status/Bar/Link/Actions        | TanStack controlled server pagination and allowlisted global sorts; complete client collections can use local search/sort. Server controls only enable supported handlers. Currency transport remains an exact decimal string. |
| Contextual evidence | Table, TableCaption, TableHead, TableBody, TableRow, TableHeader, TableCell, TableRegion | Semantic HTML for financial findings and contextual evidence; no forced pagination or conversion of decimal amounts.                                                                                                           |
| Feedback            | Loading, Spinner, Feedback, RequestError, EmptyState, Badge                              | Consistent pending/error/empty/status presentation. Existing server error messages pass through the HTTP error boundary.                                                                                                       |
| Overlays            | SidePanel, Dialog alias                                                                  | Right-side accessible panel; full screen on mobile; focus management, dirty-discard guard and busy protection. FormActions is recognized directly for its fixed footer without requiring a consumer CSS class.                 |
| Layout              | PageHeader, Card, FormActions, Accordion, AccordionTrigger                               | Shared layout classes, native disclosure semantics and existing visual hierarchy.                                                                                                                                              |

UI state (drafts, panel visibility, user selection) belongs to the component. Remote reads use feature query-option factories and TanStack Query. Remote actions use feature mutation hooks, with retry disabled and centralized organization invalidation. The design system contains no authorization or financial rules.

Styles and tokens are owned by `styles.css`, `tokens.css`, `base.css`, `theme.css` and the Select/DataTable styles. The application CSS entry preserves base → composition → theme → workspace ordering. Effective root tokens have one definition, retaining Inter, white surfaces, orange accents and semantic status colors. Application-only layouts remain in `src/styles/`; MFA enrollment secrets and backup codes wrap safely on narrow screens. Do not add ad-hoc per-page styles to replicate an existing component variant.

Verification includes native field semantics, exact decimal rendering and SidePanel footer structure tests. Browser suites cover actual keyboard interaction, responsive panels, Select, table controls and validation. A passing source check does not replace those browser checks.
