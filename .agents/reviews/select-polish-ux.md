## Specification before implementation

Use the existing Radix primitive approach for a shared Select, with visible associated label, current value/placeholder, disabled and required states, and readable validation feedback. White compact trigger, subtle neutral border, clear dark focus ring; selected/highlighted option may use the existing light orange with dark text. Do not use white small text over orange. Keep semantic financial colors unchanged. Main content background becomes white or near-white (#FAFAF9 suggested); white cards remain distinguishable by their current border, not darker page fill. Header/sidebar hierarchy remains intact.

Dropdown content uses a portal and explicit stacking above an open SidePanel, with collision handling and bounded viewport-height scrolling. Do not introduce a second modal focus trap. Keyboard acceptance: Enter/Space/Arrow keys open and select; arrows move options; Home/End/typeahead supported by primitive; Escape closes dropdown before panel; Tab continues form without losing selected value. Pointer outside closes only the dropdown when appropriate; selection must not trigger SidePanel discard. Opening/choosing must work at320/390px and zoom200 without overflow or clipped options.

Preserve actual controlled value and change callback semantics at every migrated site, including empty optional selection, organization switch, pagination size, invoice/fact services, statuses and long provider labels. Placeholder has explicit meaning; no empty string item when unsupported by Radix—map to a stable internal sentinel within the component without leaking it to API payloads. Labels must target the actual trigger through id/aria-labelledby. Required/form submission must remain real: use primitive form integration/hidden value or explicit schema validation, never silently permit missing required values after removing native validation. Field name/id/autocomplete and disabled behavior need case-by-case compatibility. Shared dropdown must not convert numeric page sizes to an invalid type or invent a selection when current value is absent from options.
